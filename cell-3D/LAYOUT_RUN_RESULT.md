## Margin 的落实

BOT 可用区域 0.1508 mm²，cell 实体面积 0.071776 mm²，利用率 47.6%；TOP 可用区域 0.702 mm²，cell 实体面积 0.348448 mm²，利用率 49.6%。可用区域面积排除了硬宏及其 keepout 和过窄 routing margin。

模块所属区域可以无缝接壤；上述实体面积利用率、每 10 行留一行、两侧各 1 μm padding 和硬宏周围 4 μm keepout 共同给后端留出空间。预留比例是当前估算假设，无法代替实际时钟树、PDN、pin access 和详细布线检查。20% bond 容量另行预留。cell 留白不等于金属容量也足够：本次结果正显示仍有拥塞。

## 算法与数学

区域采用加权软 Voronoi 分配。对于网格位置 `r` 和模块 `m`：

`q(r,m) = softmax_m((w_m - ||r-c_m||²)/τ)`

以中心 `c_m` 和面积权重 `w_m` 为变量，优化面积偏差、区域边界、紧凑性、连接距离、温度以及原布局锚点。降低 τ 使软分配趋于离散。最后统一在相同 τ 下比较检查点，并只选择满足几何硬约束的区域。

cell 坐标的目标为：

`J = α·平滑线长 + β·平滑最大路径延时 + γ·密度偏差 + δ·超密度惩罚 + η·平滑峰温`

用 `sqrt(dx²+ε²)+sqrt(dy²+ε²)` 平滑曼哈顿线长，用 `τ log Σ exp(delay/τ)` 平滑最大路径延时。功率双线性分配至热网格，温升为 `ΔT = K⁻¹p`；峰温梯度通过对称热系统的伴随解返回位置。区域变量和 cell 坐标采用 Adam 更新，并投影回合法区域；最后将 cell 放到唯一的行/site，保留 padding 和预留行。

模块间网络为 XY/YX × 两种主干层共四种候选，softmax 概率平滑离散选择，通过拥塞、bond 密度和 via 成本的梯度更新，再离散选择并放到唯一 HBT site。HBT 使用 5 μm pitch、固定窗口密度检查，最后统计 detour 消耗；没有滑动窗口 DRC 签核。

该流程借鉴可微优化思路，固定用户已有层分配，**不是 NVIDIA differentiable tier assignment 的完整复现**。真实门级网表、单元库、STA 和物理布线资源尚未提供，当前 cell 网表、路径、RC 和 IPC 外推仍为估算。
