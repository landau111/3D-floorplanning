# 3D cell 级摆放：本次估算结果

**这是已执行的合成网表代理实验，不是实际 C910 签核结果。** 真实退火候选未在目录中找到；A/B/C 为假设起点。

在 17 个已评估运行中，按离散可行优先、平均吞吐率最大选出的方案为 **`A_split__thermal__seed17`**。它在固定模块区域内用偏重热分散的梯度目标细化 cell，再优化走线层与路径。第一名指本次有限候选中的最优，不证明全局最优。

| 指标 | 估算值 |
|---|---:|
| 可行频率 | 1.361 GHz |
| 运行点总功耗 / 动态 / 泄漏 | 6.248 / 5.337 / 0.911 W |
| 运行点最高温度 | 72.03 °C |
| 最差合成路径延迟 | 0.735 ns |
| 2 GHz 标称 WNS / TNS | -245.7 ps / -29.62 ns |
| 2 GHz 标称功耗 / 最高温度 | 8.871 W / 83.40 °C |
| STREAM IPC / BIPS | 0.971 / 1.321 |
| MATMUL IPC / BIPS | 0.772 / 1.051 |
| 等权平均 BIPS / 能耗 | 1.186 / 5.267 nJ/instruction |
| F2F bond 数 | 1664 |
| 最大局部 F2F 密度 | 6300 / 20000 mm⁻² |
| GCell 路由最大利用率 / overflow | 88.2% / 0 tracks |

**主要瓶颈是时序，当前没有达到2 GHz。** 降频后WNS接近零是按最差路径选频的结果。STREAM/MATMUL IPC为原有gem5数据基础上的解析外推；较低频率使固定时间的内存等待折算周期变少，所以IPC上升不能解读成处理速度上升。

相对同一 A/B/C 起点的初始方案，平均BIPS代理变化 **+5.7%**；但初始方案有 5121 tracks overflow，属于不可行参考，不能宣称是对已可布线芯片的性能提升。

下面对每个布局的最佳可行方案保持cell与路由不变，在相同物理参数扰动下重算；没有在每个情景重新优化。

优胜方案在这8个假设情景中平均BIPS为 **1.064–1.309**，Tmax为 **65.7–85.1°C**。这是情景包络，不是置信区间，也不包括真实网表未知造成的结构性误差。

## 验证

- 完整规模解析梯度与中心差分最大相对误差：cell 2.04e-04，routing 1.99e-06。
- 已核验单元在模块区域内、row/site对齐、同一模块无重复占位、宏端口不移动；模块fence与宏本身互不重叠。
- 功率守恒最大误差 8.88e-16 W；电热固定点收敛残差 8.89e-07°C。
- 热网格从16×16加密到32×32，Tmax变化 +0.310°C，频率变化 -0.000168 GHz；本次变化低于0.5°C。
- 优胜方案连续坐标合法化平均位移 18.52 µm；性能表只使用合法化后的坐标。
- 额外测试包含热互易性、极端碰撞合法化、bond网格唯一性、超密度/零容量拒绝以及结果源码哈希一致性。
